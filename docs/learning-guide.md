## 🛠 필수 개발 환경

### 하드웨어

**입문자 추천:**
- **STM32 Nucleo 보드** (~$15)
  - ARM Cortex-M4
  - 다양한 주변장치
  - ST-Link 내장

- **ESP32 개발보드** (~$10)
  - Wi-Fi/Bluetooth
  - Arduino 호환
  - 풍부한 예제

**센서 키트:**
- MPU6050 (가속도/자이로)
- DHT22 (온습도)
- OLED 디스플레이
- 버튼, LED, 저항

### 소프트웨어

**필수:**
- STM32CubeIDE (무료) - STM32 개발
- VS Code + PlatformIO - 범용
- Git - 버전 관리

**디버깅:**
- ST-Link 유틸리티
- Serial Monitor
- Logic Analyzer (Saleae)

**시뮬레이터:**
- Proteus
- Wokwi (온라인)

## 💡 학습 팁

### 효과적인 학습 방법

1. **손으로 직접 코딩**
   - 복사/붙여넣기 금지
   - 이해하면서 타이핑

2. **디버거 활용**
   - printf 대신 브레이크포인트
   - 레지스터 값 확인

3. **데이터시트 읽기**
   - MCU 레퍼런스 매뉴얼
   - 센서 데이터시트

4. **프로젝트 중심 학습**
   - 이론만 X, 바로 실습
   - 작은 프로젝트부터 시작

5. **코드 리뷰**
   - 오픈소스 분석
   - 베스트 프랙티스 학습

### 흔한 실수와 해결책

**실수 1:** 이론만 공부
→ **해결:** 매일 최소 1시간 코딩

**실수 2:** 너무 복잡한 프로젝트 시작
→ **해결:** LED 깜빡임부터 시작

**실수 3:** 에러 메시지 무시
→ **해결:** 모든 에러 철저히 분석

**실수 4:** 하드웨어 없이 공부
→ **해결:** 최소 1개 보드 구매
