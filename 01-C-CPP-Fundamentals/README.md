# C/C++ 기초

임베디드 개발을 위한 C/C++ 핵심 개념

## 학습 내용

### 1. 기본 문법 (`basic-syntax/`)
- 변수, 자료형
- 제어문 (if, switch, for, while)
- 함수
- 배열

### 2. 자료구조 (`data-structures/`)
- 링크드 리스트
- 스택
- 큐
- 환형 버퍼 (Circular Buffer)

### 3. 알고리즘 (`algorithms/`)
- 정렬 (버블, 퀵, 삽입)
- 검색 (선형, 이진)
- 비트 조작

### 4. 메모리 관리 (`memory-management/`)
- 포인터
- 동적 메모리 할당
- 메모리 누수 방지
- 스택 vs 힙

## 임베디드 특화 포인트

- **메모리 효율성**: 제한된 RAM/ROM 고려
- **실행 속도**: 최적화된 알고리즘
- **안정성**: 메모리 오버플로우 방지
- **이식성**: 플랫폼 독립적 코드
