# 임베디드 시스템 개발 포트폴리오

임베디드 소프트웨어 엔지니어 취업을 위한 학습 및 프로젝트 저장소

## 📚 학습 로드맵

### 1️⃣ C/C++ 기초 (`01-C-CPP-Fundamentals/`)
- ✅ C 언어 기본 문법
- ✅ 포인터와 메모리 관리
- ✅ 자료구조 (링크드 리스트, 큐, 스택)
- ✅ 임베디드 최적화 알고리즘

### 2️⃣ MCU 펌웨어 개발 (`02-MCU-Firmware/`)
- ✅ GPIO 제어
- ✅ 타이머/PWM
- ✅ ADC/DAC
- ✅ 인터럽트 처리

### 3️⃣ RTOS (`03-RTOS/`)
- ✅ FreeRTOS 기초
- ✅ Task 관리
- ✅ Semaphore, Mutex, Queue
- ✅ 실시간 스케줄링

### 4️⃣ 통신 프로토콜 (`04-Communication-Protocols/`)
- ✅ UART 통신
- ✅ SPI 통신
- ✅ I2C 통신
- ✅ CAN 버스

### 5️⃣ 드라이버 개발 (`05-Driver-Development/`)
- ✅ 디바이스 드라이버
- ✅ HAL 추상화 레이어
- ✅ 부트로더

### 6️⃣ 포트폴리오 프로젝트 (`06-Portfolio-Projects/`)
실무 수준의 완성 프로젝트

### 7️⃣ 면접 준비 (`07-Interview-Prep/`)
- ✅ 기술 면접 질문/답변
- ✅ 코딩 테스트
- ✅ 하드웨어 지식

## 🛠 개발 환경

- **언어**: C, C++
- **플랫폼**: ARM Cortex-M (STM32, ESP32 등)
- **도구**: GCC, Make, CMake, OpenOCD
- **RTOS**: FreeRTOS
- **버전 관리**: Git
