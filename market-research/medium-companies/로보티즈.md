# 로보티즈 (ROBOTIS) ✅ 2025 채용중

## 기업 개요
- **설립:** 1999년 (26년 역사)
- **상장:** 비상장
- **직원 수:** 162명
- **본사:** 서울특별시 강서구
- **대표:** 미공개

## 사업 분야
- 로봇 전용 액추에이터 (DYNAMIXEL)
- ROS 기반 로봇 플랫폼
- 임베디드 제어 시스템
- 교육용 로봇
- 서비스 로봇 솔루션

## 임베디드 개발 부문

### 로봇 제어기 개발
- OpenCR 임베디드 보드 개발
- ARM Cortex-M 기반 제어 시스템
- ROS 지원 임베디드 모듈
- TurtleBot3 메인 컨트롤러

### 액추에이터 제어
- DYNAMIXEL 서보 모터 펌웨어
- 모터 통합 제어 시스템
- 감속기/컨트롤러/통신 일체형
- 로봇 관절 모듈화

### 임베디드 시스템 통합
- 로봇 플랫폼 시스템 설계
- 센서 인터페이스 개발
- 실시간 제어 알고리즘

## 기술 스택

### 언어
- C/C++ (펌웨어)
- Python (ROS, AI)

### 플랫폼
- **OpenCR** (Open-source Control module for ROS)
- ARM Cortex-M
- Linux Embedded
- ROS/ROS2 (Robot Operating System)

### 통신
- UART
- SPI
- I2C
- RS485
- TTL Communication (DYNAMIXEL)

## 주요 제품

### DYNAMIXEL (다이나믹셀) - 로봇 전용 액추에이터
- **모듈화된 스마트 서보 모터**
- 모터 + 감속기 + 컨트롤러 + 통신 일체형
- 로봇 관절 구성에 최적화
- TTL/RS485 통신 지원
- 위치/속도/토크 제어 가능

### 제어기
- **OpenCR 1.0** - ROS 지원 오픈소스 임베디드 보드
  - TurtleBot3 메인 컨트롤러
  - ARM Cortex-M7 (STM32F746)
  - ROS 네이티브 지원
  - Arduino IDE 호환

### 로봇 플랫폼
- **TurtleBot3** - 세계 표준 ROS 플랫폼
- **OpenManipulator** - 오픈소스 로봇 팔
- 교육용 로봇 키트 (OLLO, DREAM, SMART)
