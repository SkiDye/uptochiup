# 토르드라이브 (ThorDrive) ✅ 2025 채용중

## 기업 개요
- **설립:** 2016년
- **상장:** 비상장
- **직원 수:** 미공개
- **본사:** 대한민국
- **대표:** 이호진
- **투자 유치:** 약 400억원 누적

## 사업 분야
- AI 기반 자율주행 풀스택 솔루션
- 실내 무인운송 시스템
- 화물/물류 자율주행
- 공항 자율주행 시스템
- 산업용 자율주행 로봇

## 임베디드 개발 부문

### 자율주행 차량 제어
- 실시간 차량 제어 시스템
- RTOS 기반 제어 펌웨어
- 모터 제어 알고리즘
- CAN 통신 기반 차량 제어

### 센서 융합 시스템
- Lidar, Camera, Radar 센서 통합
- 실시간 센서 데이터 처리
- IMU 기반 위치 추정
- 센서 캘리브레이션

### 임베디드 자율주행 플랫폼
- Perception 알고리즘 임베디드 구현
- Decision Making 시스템
- Path Planning 알고리즘
- 3D 고정밀 맵 처리

### 하드웨어 전장 개발
- 자율주행 ECU 개발
- 전장 시스템 설계
- 센서 인터페이스 하드웨어
- 전원 관리 시스템

## 기술 스택

### 언어
- C/C++ (실시간 제어)
- Python (AI/알고리즘)

### 플랫폼
- RTOS (Real-Time OS)
- Linux Embedded
- ROS/ROS2 (Robot Operating System)
- AUTOSAR (우대)

### 자율주행 기술
- **센서 융합:** Lidar, Camera, Radar, IMU
- **AI 인식:** 딥러닝 기반 객체 인식
- **경로 계획:** Path Planning, Motion Planning
- **3D 맵:** 고정밀 맵 생성 및 활용
- **위치 추정:** SLAM, Localization

### 통신
- CAN, CAN-FD
- Ethernet (차량용)
- V2X (우대)
- WiFi, LTE/5G

### 개발 도구
- Git
- Docker
- CI/CD 파이프라인
- 시뮬레이터 (CARLA, Gazebo 등)

- 실내 자율주행 기술 상용화

**화물 견인 자율주행차 (2024년 12월)**

- Motrex와 협력 개발
- 항공기 주기장 ↔ 화물터미널 간 화물/수하물 운송
- 공항 물류 자동화
