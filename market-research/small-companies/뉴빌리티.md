# 뉴빌리티 (Neubility) ✅ 2025 채용중

## 기업 개요
- **설립:** 2017년 10월
- **상장:** 비상장
- **직원 수:** 114명 (2024년 4월 기준)
- **본사:** 대한민국
- **대표:** 이상민
- **투자 유치:** 296억원

## 사업 분야
- 자율주행 배달 로봇
- 로봇 배달 플랫폼 (RaaS)
- 도심 자율주행 기술
- 라스트 마일 배송 자동화

## 임베디드 개발 부문

### 자율주행 로봇 제어
- 카메라 기반 V-SLAM
- 실시간 위치 추정 및 매핑
- 도심 자율주행 제어 시스템
- 장애물 회피 알고리즘

### 임베디드 시스템
- 로봇 제어 펌웨어
- 센서 융합 시스템
- 모터 제어 및 구동부
- 실시간 제어 RTOS

### RaaS 플랫폼
- 로봇 관리 시스템
- Fleet 관리 플랫폼
- 사업 파트너 연동 API
- 클라우드 통신

## 기술 스택

### 언어
- C/C++ (임베디드 제어)
- Python (자율주행 알고리즘)

### 자율주행 기술
- **V-SLAM** (Visual SLAM) - 카메라 기반
- Vision AI (객체 인식)
- 경로 계획 (Path Planning)
- Localization (위치 추정)

### 센서
- Camera (주력 센서)
- IMU
- Encoder
- GPS (보조)

### 플랫폼
- ROS/ROS2
- Embedded Linux
- RTOS

### 통신
- WiFi, LTE/5G
- Cloud API
- MQTT

## 회사 특징

### 도심 자율주행 특화
- 서울 등 복잡한 도심 환경 최적화
- GPS 부정확한 지역에서도 작동
- 카메라 기반 V-SLAM으로 비용 절감

### 배달로봇 '뉴비' (Neubie)
- 도심 보도 주행 최적화
- 실내외 자율주행
- 안전한 배달 서비스

### 광범위한 서비스 지역

- 도심 지역

- 골프장
- 캠핑장

**해외**
- 사우디아라비아 네옴시티
