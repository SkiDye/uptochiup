# 에바 (EVAR) ✅ 2025 채용중

## 기업 개요
- **설립:** 2018년 11월
- **상장:** 비상장
- **직원 수:** 약 71명 (2024년 기준)
- **본사:** 경기도 성남시 분당구 (제2판교 벨리)
- **대표:** -

## 사업 분야
- 전기차 충전기 개발
- 이동형 자동 충전 솔루션
- 자율주행 로봇
- 스마트 충전 인프라

## 임베디드 개발 부문

### 전기차 충전기 제어
- 임베디드 충전기 제어 시스템
- MCU 기반 펌웨어 개발
- IoT 플랫폼 연동
- RTOS 기반 실시간 제어

### 스마트 로드밸런싱
- 한정된 전력 자원 분배 알고리즘
- 다수의 충전기 동시 제어
- 전력 최적화 시스템

### 화재 감지 시스템
- 전기차 화재 감지 센서 통합
- 실시간 모니터링
- 긴급 대응 시스템

## 기술 스택

### 언어
- C/C++ (임베디드 펌웨어)
- Python (서버/데이터 분석)
- Embedded C

### 플랫폼
- MCU (Cortex-M 시리즈)
- RTOS (FreeRTOS)
- Linux Embedded
- IoT Platform

### 통신
- Ethernet
- WiFi
- BLE (Bluetooth Low Energy)
- CAN
- OCPP (Open Charge Point Protocol)

### 개발 도구
- Embedded IDE
- IoT 클라우드 플랫폼
- 충전기 테스트 장비

## 채용 정보

### 채용 방식
- **수시 채용:** 상시 진행
- **경력 채용:** 임베디드 개발자 우선
- **신입 채용:** 간헐적 진행

### 주요 직무

**임베디드 개발자**
- 전기차 충전기 펌웨어 개발
- MCU 기반 제어 시스템
- RTOS 응용 개발
- Cortex-M, nRF, ESP 등 IoT MCU 플랫폼
- BLE, WiFi 무선 통신

**전력 제어 알고리즘 개발**
- 스마트 로드밸런싱 알고리즘
- 전력 최적화
- 다중 충전기 제어

**IoT 플랫폼 개발**
- 충전기-서버 통신 프로토콜
- 클라우드 연동
- 모니터링 시스템

### 자격 요건

**필수 역량**
- C/C++ 프로그래밍 능력
- MCU 기반 임베디드 개발 경험
- RTOS 개발 경험
- 전기/전자 기본 지식

**우대 사항**
- 전기차 충전기 개발 경험
- 전력 전자 회로 이해
- OCPP 프로토콜 경험
- IoT 클라우드 플랫폼 경험
- BLE, WiFi 통신 개발
- 전기 안전 규격 지식

## 회사 특징

### 삼성전자 C-Lab 스핀오프
- 2018년 삼성전자 C-Lab에서 분사
- 삼성 DNA 기반 혁신 기업

### 주요 제품
- **Smart EV Charger 2.0:** 전기차 화재감지 솔루션 탑재
- **스마트 로드밸런싱:** 세계 최다 규모 (2만대 가까운 완속 충전기 공급)
- **이동형 충전 솔루션**
- **자율주행 충전 로봇**

### 수상 및 인증
- **CES 2022:** 2개 부문 혁신상 (스마트 시티, 지속 가능성/에코 디자인/스마트 에너지)
- 단일 제품 2개 부문 동시 수상 최초 사례
- **CES 2022~2023:** 2년 연속 5개 혁신상

### 투자
- **시리즈 A:** 약 55억원
- **투자자:** 현대자동차, DSC인베스트먼트, 슈미트, GS글로벌, SK렌터카, 신한캐피탈, 젠티움파트너스, 삼성벤처투자

### 글로벌 진출
- 캐나다: 250만 달러 공급 계약
- 북미 시장 공략 중
- 전국 2만대 가까운 완속 충전기 공급 (국내)
