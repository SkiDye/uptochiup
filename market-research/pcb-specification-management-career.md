## 사양관리 직무 상세 분석

### 핵심 업무

1. **Gerber 데이터 검토 및 편집**
   - 고객 제공 GBR file 검토
   - 작업 가능한 file로 변환/수정
   - DFM (Design for Manufacturing) 검토

2. **사양 확인 및 문서화**
   - 제품 사양 확인
   - 작업지시서 발행
   - 수주접수 관리

3. **고객 커뮤니케이션**
   - 고객 의도 파악
   - 공정능력 대비 협의
   - DFM 결과 공유 및 조율

4. **CAM 작업**
   - CAM350, Genesis, InCAM 등 사용
   - 레이어 정리 및 최적화
   - 제조 데이터 출력

## 필수 역량 및 스킬

### 필수 소프트웨어

| 분야 | 도구 |
|------|------|
| CAM | CAM350, Genesis, InCAM |
| 설계 확인 | OrCAD, PADS, Allegro, Altium |
| 검증 | DFM Tool, DRC Check |
| 문서 | Excel, 사양서 양식 |

### 기술 역량

1. **Gerber 파일 분석**
   - Layer 구조 이해
   - Drill 데이터 검토
   - Aperture 관리

2. **DFM (Design for Manufacturing)**
   - 제조 가능성 검토
   - 공정능력 대비 설계 검증
   - 고객 협의 사항 도출

3. **PCB 제조 공정 이해**
   - 적층 구조 이해
   - 도금, 에칭 공정 기본 지식
   - 품질 기준 (IPC 표준)

### 소프트 스킬

- 고객 커뮤니케이션 능력
- 꼼꼼한 검토 능력
- 문서화 능력
- 팀 협업 능력

## 이직 전략

### GPN에서의 경력 활용

**강점:**
- 자동차/방산 분야 사양관리 경험
- 품질 시스템 (AS9100) 경험
- 고객 대응 경험

**이직 시 어필 포인트:**
1. 방산/자동차 등 고신뢰성 PCB 사양관리 경력
2. 고객사 DFM 협의 경험
3. CAM 작업 및 사양검토 실무 능력
4. 품질 인증 시스템 이해

### 추천 이직 방향

1. **수평 이동 (동일 직무, 다른 회사)**
   - 엠에스이, 신성에스지, 스마트코리아피씨비
   - 연봉 협상력 높음
   - 적응 빠름

2. **상향 이동 (중견/대기업)**
   - 이수페타시스, 스템코, 심텍
   - 경력 3년 이상 시 지원 가능
   - 연봉 상승폭 큼

3. **전문성 강화 (FPCB, HDI 등)**
   - 특수 PCB 분야로 확장
   - 스마트폰/자동차 전장 시장 성장
